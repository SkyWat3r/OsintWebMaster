## Idees restantes si on veut aller encore plus loin

- Differencier les types d'ecoles: maternelle, primaire, college, lycee, universite.
- Differencier les batiments publics: mairie, commissariat, tribunal, administration.
- Differencier les arrets de transport avec les tags reseau/operateur si disponibles.
- Differencier les commerces alimentaires: epicerie, primeur, poissonnerie, supermarche, boulangerie, boucherie.
- Differencier les parkings: voiture, velo, moto, entree de parking, parking couvert.
- Differencier les panneaux: danger, obligation, interdiction, direction, limitation de vitesse, si OSM fournit assez de tags.
- Ajouter des filtres par marque ou operateur quand les tags `brand` ou `operator` existent.
